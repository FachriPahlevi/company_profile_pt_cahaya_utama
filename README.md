# Company Profile PT. Cahaya Utama 🌟

Selamat datang di repository **Company Profile PT. Cahaya Utama**, proyek ini bertujuan untuk menghadirkan profil perusahaan PT. Cahaya Utama secara profesional dan menarik secara digital. Website ini dirancang responsif, modern, dan user-friendly untuk meningkatkan kepercayaan pengguna terhadap perusahaan.

---

## ✨ Fitur Utama
- **Desain Responsif**: Tampilan yang optimal di berbagai perangkat (desktop, tablet, dan mobile).
- **Navigasi Mudah**: Navigasi yang intuitif untuk pengalaman pengguna yang lebih baik.
- **Informasi Perusahaan**: Menampilkan informasi penting seperti visi, misi, layanan, dan portofolio.
- **Galeri Foto**: Menampilkan dokumentasi visual perusahaan.
- **Formulir Kontak**: Mempermudah pelanggan untuk menghubungi perusahaan secara langsung.

---

## 🛠️ Teknologi yang Digunakan
- **Frontend**:
  - HTML5, CSS3, dan JavaScript
  - Framework: [Bootstrap](https://getbootstrap.com/) untuk desain responsif
- **Backend**:
  - [Laravel](https://laravel.com/) sebagai framework PHP
- **Database**:
  - MySQL
- **Animation & Icon**:
  - [Framer Motion](https://www.framer.com/motion/) untuk animasi interaktif
  - [React Icons](https://react-icons.github.io/react-icons/) untuk ikon
- **Version Control**:
  - Git dan GitHub
